# ארבעת המינים - ניהול הזמנות

דף ניהול פשוט להזמנות של ארבעת המינים, עם אפשרות להוסיף הזמנות ידנית או לייבא קובץ CSV מ-Google Sheets.

## מה כולל האתר

- הוספת הזמנה עם:
  - שם לקוח
  - טלפון
  - סוג סט
  - כמות
- ייבוא קובץ CSV
- סיכום לפי סוג מוצר
- רשימת כל ההזמנות
- סיכום לפי לקוח
- שמירה מקומית בדפדפן
- יצוא ל-CSV

## פורמט CSV מומלץ

ב-Google Sheets צריך שיהיו עמודות עם שמות כאלה:

- שם
- טלפון
- סט
- כמות

דוגמה:

```csv
שם,טלפון,סט,כמות
אבי כהן,0501234567,מהודר א,2
רותי לוי,0527654321,מהודר ב,1
```

המערכת תתאים גם שמות כמו:

- שם לקוח
- לקוח
- טלפון
- phone
- סוג
- product
- כמות
- quantity

## איך להריץ

1. פתח את תיקייה במחשב.
2. הרץ שרת מקומי:

```bash
python -m http.server 8000
```

3. פתח בדפדפן:

```text
http://localhost:8000
```

## היכן נשמרו ההזמנות

הנתונים נשמרים ב-localStorage של הדפדפן, כך שהאתר זוכר את ההזמנות גם אחרי רענון.

## אם תרצה להמשיך

אפשר להוסיף בהמשך:

- מסך פרטי הזמנה לכל לקוח
- שליחת WhatsApp אוטומטית
- חיבור למסד נתונים
- תשלומים ומעקב מצב הזמנה
